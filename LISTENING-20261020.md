# Question listening release

- Phonics: automatic Part instruction once, then the current clue; correct completion advances, wrong choices stay available for a retry without rewriting the first score.
- Phonics Story: six tasks per Unit checkpoint, one exact textbook sentence per task, no visible transcript or whole-story button. Thirty-two dedicated 1200px WebP illustrations remain mounted between sentence changes. Prompts and generation records are in `khoa-hoc/story-illustrations-sources.json` (built-in imagegen).
- FF and Discover listening practice: automatic current-question narration and advance through the original submission path. Reading and grammar sheets retain their existing layout. The 102 continuous dictation sheets retain all answer fields and saved drafts. Enter focuses the next empty blank; moving to a new sentence plays its short clip. The full original track remains available as an explicit manual alternative. Of 2,108 sentence mappings, 147 low-confidence or mismatching source alignments use clearly labelled native-English Titi narration of the saved classroom transcript; these must not be described as original recording excerpts. Original recordings and transcript text/answers are not rewritten.
- Discover Progress Tests: 72 original audio Parts, 279 question mappings. The source MP3s are unchanged; the per-question copies and the Part instruction are under `discover-exam/audio/questions-v1/`. Numbered a/b subquestions share the appropriate source item clip. Original fields, points, answer matching and listening-play limits are retained. Enter commits the current filled question and scrolls to the next one; choices advance automatically. Whole sheets, shared pictures and drafts remain visible/saved.
- Văn Lang: `van-lang/exams/source/` contains 17 existing digital source banks from the verified Tháng 6/2027 classroom folders. Seventeen 40-question source tests and the three existing 40-question cumulative checkpoints form 20 levels / 800 questions; checkpoints sample their already-taught four-test groups. Five later tests are appended without moving existing checkpoints. Source IDs, original emphasis, illustrations, answers and detailed explanations are retained. Existing class-admission mappings are retained; appended tests require their own published classroom lesson to have been taught. Practice saves have a new namespace; old game saves and grammar saves are not overwritten.
- Văn Lang gap-fill and long passage questions do not start automatic narration. Explicit speaker actions remain separate.
- Hidden listening: the 32 self-contained Unit scenes and praise recordings are also shipped in this repository, avoiding an independent media deployment dependency. Selected Unit scenes preload from the checkpoint menu. JSON fetches retry with cache reload, failed image promises are evicted, and a failed opening offers a retry/back action without clearing progress.
- A partly completed Phonics run retains answers for unchanged questions. Removed IDs cannot contribute points; migrated work cannot create a speed-ranking record.

Validation: `node --test` on tracked test files plus `listening-flow.test.cjs`; desktop/390px browser checks cover source clipping playback, one Part instruction, auto-next, saved-input reload, fixed Story artwork, silent Văn Lang gap entry, and Hidden loading without the separate media release.

Rebuild the trusted scoring curriculum with `node game-service/leaderboard/build.mjs` whenever question banks change, then deploy the helper1 Worker before publishing the static release.
