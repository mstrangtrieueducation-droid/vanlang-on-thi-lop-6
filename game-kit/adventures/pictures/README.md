# Phonics picture atlas prompts

Four original transparent PNG sheets generated with imagegen. Each sheet is 4×4.
Runtime selects cells with CSS background-position; the original PNGs are copied
unchanged. Word/cell mapping is in khoa-hoc/phonics.cjs. Ambiguous cells (snow,
line, kid, moon) are excluded from picture questions. Options do not print words
until the answer is reviewed.

+## Sheet 1

Production game asset: ONE square sprite atlas, exactly a 4-column by 4-row grid of 16 separate cute polished chunky 3D illustrations for a primary-school English phonics listen-and-choose picture exercise. Transparent background throughout; no grid lines, no cell backgrounds, absolutely no text or letters, labels, numbers, watermarks. Camera front three-quarter, soft studio lighting, rich bright colors, crisp edges, plush clay-toy volume with realistic subtle highlights; each subject instantly identifiable. Each of the 16 equal square cells contains exactly ONE isolated subject centered within its cell, occupying about 65% of the cell width and height, with generous transparent margin so no part crosses a cell boundary. All cells precisely equal and perfectly aligned. Do not add props that confuse vocabulary. Reading order left to right, top to bottom: row 1: apple; ball; cat; dog. Row 2: egg; fish; goat; hat. Row 3: insect (a beetle); jam (a jar of red jam, no label); kite; lion. Row 4: moon (crescent); nest; octopus; pig. Render the atlas at high resolution, as sharp as possible for cropping into game cards using CSS.
