# Cô giáo Titi — approved human Chibi

The user approved demo v3 based on her supplied portrait and the centre's full navy/gold/white logo. The character name remains **Cô giáo Titi**.

`welcome.webp` is the approved design. `correct.webp`, `regret.webp`, `thinking.webp` and `rocket.webp` are reference-guided built-in ImageGen edits of that design. Exact prompts and final asset paths are recorded in `sources.json`. Transparent WebP preserves the artwork's alpha channel.

The shared `game-kit/teacher-brand.css` replaces teacher artwork at existing game and private-dashboard presentation points. Internal `teacher-fox` classes remain compatibility hooks. Existing speech, gameplay, timing, scoring, admission, saved progress and pointer handlers are unchanged. The timer changes only its image URL.
